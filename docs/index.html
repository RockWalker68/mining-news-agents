What I can say is that the test is whether the affected area sits in the mine plan that feeds 2027 tonnes. If it does, it becomes a supply issue. In my experience, operational problems usually show first in a production table in the quarterly report, then in a guidance revision. A force majeure notice is the strongest signal and tends to come last.

On Dumbwa and the Alaska results: "More than twice as wide" means nothing without the hole angle. A hole that cuts a zone at 30 degrees to its plane gives a downhole width about twice the true width. So I'd need:

  • The downhole width and the company's estimated true width for each intercept, with the method and the hole dip stated.
  • Several holes across the strike, not one highlight.
  • A comparison with the existing resource model's average true width and grade for the same domain.

Until a company supplies those, I'd treat the width claim as a description of drilling, not a resource signal. I'm also retracting any sense that the intercept alone carries weight.
